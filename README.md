# Quiz de Português

Projeto simples de quiz desenvolvido com **HTML, CSS e JavaScript puro** (sem frameworks).

## Sobre o projeto

Este projeto foi criado para praticar lógica de programação e manipulação de DOM com JavaScript.
O usuário inicia pela tela de apresentação e responde perguntas objetivas de português.

Ao final, o sistema mostra:

- quantidade de acertos
- pontuação final
- feedback de desempenho

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Estrutura básica

```bash
.
├── index.html          # Tela inicial (apresentação + botão iniciar)
├── index.css           # Estilos da tela inicial
├── portugues.html      # Tela do quiz
├── portugues.css       # Estilos do quiz
├── portugues.js        # Lógica do quiz
└── sons/               # Efeitos sonoros (opcional)
```

## Como executar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` no navegador

Ou, se preferir, use a extensão **Live Server** no VS Code.
